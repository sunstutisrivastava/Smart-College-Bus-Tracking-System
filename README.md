# 🚌 Smart College Bus Tracking System

A modern transportation management system that enables real-time bus tracking, route management, attendance, notifications, and analytics for students, drivers, and administrators.

---

## 📖 Overview

The Smart College Bus Tracking System is designed to enhance the safety, efficiency, and transparency of college transportation services. It allows students to track buses in real time, check estimated arrival times, receive important notifications, and access route information. Drivers can manage trips and update bus status, while administrators can monitor the entire transportation system through a centralized dashboard.

---

## ✨ Features

### 👨‍🎓 Student
- Track bus location in real time
- View bus routes and schedules
- Check estimated arrival time (ETA)
- Receive notifications for bus arrival and delays
- View attendance history

### 🚌 Driver
- Start and end trips
- Share live bus location
- Update trip status
- Mark student attendance

### 👨‍💼 Administrator
- Manage buses, drivers, and students
- Create and assign routes
- Monitor active buses
- View transportation analytics
- Generate reports

## 🚀 Installation

### Clone the repository

```bash
git clone https://github.com/sunstutisrivastava/smart-college-bus-tracking-system.git
```

### Install dependencies

```bash
npm install
```

### Configure environment variables

Create a `.env` file and add the required credentials.

```env
PORT=5000
MONGODB_URI=your_mongodb_connection_string
JWT_SECRET=your_secret_key
GOOGLE_MAPS_API_KEY=your_google_maps_api_key
```

### Start the application

Backend

```bash
npm start
```

Frontend

```bash
npm run dev
```
